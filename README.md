# JavaScript — Arrays & Functions

## What it does
- Finds the maximum number in an array.
- Calculates the sum of all elements.
- Counts the number of odd numbers.

The sample array used is `[4, 8, 2, 11, 6, 7, 10]`, producing:

```
Array:-[4,8,2,11,6,7,10]
Maximum number:11
Sum of all elements:48
Count of odd numbers:2
```

## Files
- `script.js` — single JavaScript file (Node and browser).
- `index.html` — simple web page that shows only the output.
- `style.css` — simple styling.

## Run

With Node.js:
```bash
node script.js
```

In the browser:
Open `index.html`.
